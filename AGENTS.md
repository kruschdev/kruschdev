# `@kruschdev` GitHub Profile Repository (`kruschdev`) Agent Guide

> Last updated: 2026-11-27

## Safety & Invariants
- **`INV-12` Span-Anchored Headings**: Preserve anchored section headings in `README.md` (`### 🛠️ Open-Source Engineering & Failure-Mode Design` and `### 🤝 Collaborating in External Codebases: Maintainer-Merged Upstream PRs`).
- **Solo Voice & Zero-Leak (`INV-SOLO-VOICE-01`)**: Write strictly in singular first-person (`"I"`, `"my"`, `"me"`), use zero em dashes, and never expose private IPs, internal hostnames, or unreleased private project names.
- **Metric Parity**: Keep benchmark scores, active npm package counts (`10`), Official MCP Registry servers (`8/8` `dev.krusch/*`), and merged upstream PR links synchronized with `krusch.dev` and `spec.md`.

## Key Files
- `README.md`: Public GitHub profile overview (`github.com/kruschdev`).
- `CONTRIBUTING.md`: Contribution and verification guidelines across `@kruschdev` open-source packages.
